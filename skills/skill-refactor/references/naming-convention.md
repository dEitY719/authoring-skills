# Skill Naming Convention — pointer

The canonical text lives in one place so the audit rule and the refactor rule
can never disagree about the same convention:

**`skills/skill-check/references/naming-convention.md`**

Read it before touching a `name:` field. The section that governs a refactor is
**"Refactor rule (`authoring:skill-refactor` Step 3b)"**; the short version is
that `name: category:action` colon form is the dotfiles SSOT convention and must
be preserved byte-for-byte, while a marketplace repo such as this one requires
the bare directory name instead.
